# 🤖 AI Multi-Agent Decision Support System

## 📌 Project Overview
AI Multi-Agent Decision Support System is a Python-based application that analyzes sales data, provides AI-driven recommendations, predicts future sales, and generates PDF reports through an interactive Streamlit dashboard.

## ✨ Features
- 📂 Upload Excel Sales File
- 📊 Sales Analysis
- 💡 AI Recommendations
- 📈 Sales Prediction
- 📊 Interactive Charts
- 📄 PDF Report Generation

## 🛠️ Technologies Used
- Python
- Pandas
- Scikit-learn
- Streamlit
- Plotly
- ReportLab

## 🚀 How to Run

```bash
pip install -r requirements.txt
python -m streamlit run app.py
```
